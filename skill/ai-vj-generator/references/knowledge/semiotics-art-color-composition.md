# 4. SEMIOTICS

Use semiotics to understand how visual elements communicate meaning.

The Skill should reason about:

- sign
- signifier
- signified
- icon
- index
- symbol
- metaphor
- metonymy
- visual rhetoric
- cultural associations
- abstraction
- repetition
- contrast
- transformation
- absence
- presence
- scale
- hierarchy
- visual codes

Do not treat semiotics as academic decoration.

Use it to answer:

> What does this visual element mean?

Examples:

### Circle

Possible meanings:

- cycle
- totality
- orbit
- unity
- infinity
- enclosure
- system

### Fragmentation

Possible meanings:

- collapse
- memory
- instability
- violence
- transformation
- digital corruption
- multiplicity

### Grid

Possible meanings:

- order
- control
- system
- measurement
- architecture
- computation
- bureaucracy
- digital infrastructure

### Organic growth

Possible meanings:

- life
- evolution
- emergence
- mutation
- expansion
- intelligence

The Skill must choose meanings according to the briefing and cultural context.

Never assume that one symbol has one universal meaning.

# 5. SEMIOTIC TRANSLATION PIPELINE

When the briefing contains an abstract idea, translate it:

```text
ABSTRACT IDEA
↓
ASSOCIATION
↓
VISUAL SIGN
↓
FORM
↓
MOTION
↓
TEMPORAL EVENT
```

Example:

```text
"I want transformation."

Concept:
metamorphosis

Visual sign:
unstable structure

Form:
hybrid geometry

Motion:
continuous deformation

Temporal event:
topology changes from one state to another
```

This prevents abstract concepts from becoming generic visual effects.

- where the eye goes
- how the image begins

# 7. ART DIRECTION: HIERARCHY

Every composition should have hierarchy.

At minimum:

```text
PRIMARY
SECONDARY
TERTIARY
```

The primary element communicates the main concept.

Secondary elements support it.

Tertiary elements create atmosphere or detail.

Do not make every element equally important.

Visual hierarchy may be created through:

- scale
- contrast
- brightness
- saturation
- motion
- sharpness
- density
- depth
- position
- frequency
- repetition

---

# 8. ART DIRECTION: CONTRAST

Use contrast deliberately.

Possible contrast systems:

```text
large / small
fast / slow
bright / dark
dense / sparse
sharp / soft
organic / geometric
static / dynamic
ordered / chaotic
opaque / transparent
warm / cool
smooth / granular
visible / hidden
```

Contrast is a compositional engine.

Do not add effects simply because they look impressive.

# 12. COLOR AS MOTION

Color can also animate.

Examples:

```text
slow hue migration
temperature shift
saturation accumulation
value collapse
spectral emergence
color-triggered events
```

Do not automatically animate hue.

A static palette can be more powerful.

Color change must have a reason.

---

# 13. COLOR AND SEMIOTICS

Color should support meaning.

Examples:

```text
red:
danger / energy / violence / heat / urgency

blue:
distance / technology / cold / depth / calm

green:
growth / toxicity / nature / biological systems

white:
light / purity / emptiness / information

black:
void / absence / sophistication / unknown / negative space

violet:
mystery / artificiality / spirituality / altered states
```

These are contextual associations, not universal laws.

Always consider the briefing and cultural context.
