    AI VJ Generator

    Aguardando briefing

    Esta interface não inventa animações. Cada projeto nasce de um briefing conversado com o Claude, que analisa o texto, as imagens e os vídeos que você enviar e escreve um sistema visual do zero. Não há presets, exemplos nem modelos pré-prontos.

    1. No chat do Claude, digite /vj e descreva o set.
    2. Responda às perguntas. Anexe imagens ou vídeos de referência na conversa.
    3. O Claude gera o projeto e abre esta interface já carregada.
    Este projeto tem camadas de código. Elas rodam como programa neste navegador. Um filtro bloqueia rede, armazenamento e relógio, mas não é uma caixa de areia isolada: autorize só se confiar em quem gerou o arquivo. Sem autorização elas ficam em branco.
